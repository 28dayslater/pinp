# Iteration Specs

This directory contains iteration documentation for pinp.

The files here are work records: they capture what an iteration was meant to do, possible
design constraints at the time, possibly what is deferred, implementation notes, etc.
They are not intended to be the authoritative language manual, and they are not expected
to read like a polished public documentation.

Because these files are historical iteration records, they may contain rough wording, conversational
notes, stale implementation details, or ideas that were later revised. That is acceptable. The
perceived quality of these files from the point of view of an external human reader is not critical;
clarity for ongoing development is the priority.

Authoritative user-facing language documentation belongs under `docs/` once enough features exist to
justify a consolidated manual. That manual may draw from these specs, but it should present the
current language as it is, not preserve every iteration's design history.
